# AI-Aware CFG++ Examples

Experimental examples exploring configuration features for AI/ML workflows.

## Examples

### `hash-validation.cfgpp`
Demonstrates configuration integrity checking with hash validation.

### `compression-config.cfgpp`
Shows compression-related configuration settings.

## Note

These are experimental/speculative examples. The features shown here (hash validation, compression) are not yet implemented in the parser — these files demonstrate what the syntax *could* look like.
